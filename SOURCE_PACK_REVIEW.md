# Bridge source review

## Original PTJ packs

The six PTJ projects retain their original filenames, order and learner-facing
APIs. PTJ1 through PTJ4 contain a Java and C++ branch; PTJ5 is Java-only and PTJ6
is C++-only. Complete contracts and a Python starting behavior accompany every
importable starter. Python examples explain the source behavior being ported;
completed target-language references remain separately under `solution/`.

The native gate compiles all 20 starter/reference programs with Java 21 and
C++17, then compiles independent API harnesses against every pair. It checks
matching callable names, incomplete starter failures, ordinary/boundary values,
collection order/ties/non-mutation, state-preserving rejected account actions,
integer-minimum magnitude rejection, console input and cancellation. This is
source/runtime evidence; it does not establish site IDE import/export behavior
or production deployment.

## Generated BRG packs and graphics

All 40 BRG starter bodies are the same unfinished Java `computeScore` loop;
all 40 reference bodies implement the same even/odd scoring algorithm. Those
files cannot establish the workflow, function, collection, class, graphics,
C++ stream/vector, or capstone subjects named in their catalog titles.
The files remain intact while the site catalog is corrected. They are outside
this native PTJ gate and must not be represented as reviewed assignments.

The seven `graphics/` JavaFX programs depend on a separate GUI/toolchain. They
are historical support examples, not console IDE projects or tested starter/
reference pairs. Browser/native graphics workflow validation remains open.

The required capstone currently points at one of the duplicated BRG scoring
packs. Replacing that assignment and retiring unsupported duplicate links are
pending site/source follow-ups, not completed by this PTJ-only correction.
