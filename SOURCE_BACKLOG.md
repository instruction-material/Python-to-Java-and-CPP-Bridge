# Source Backlog Ledger

The folders below retain historical/support material. The corresponding catalog
correction removes their assignment links; source retention does not imply an
active, complete or independently verified assignment. No historical source
program is deleted or rewritten by this change.

The 40 `BRG*` packs have identical unfinished Java scoring bodies and identical
reference scoring algorithms under different subject titles. They do not teach
the named function, class, C++ or capstone subjects. The required capstone is
replaced by the separately authored `PTJ7-Task-Tracker-Capstone` port.

`graphics/` retains seven JavaFX support examples requiring their own GUI setup;
these are outside the dependency-free console/native assignment gate. Promotion
requires a specific learner brief, distinct purpose, accurate starter/reference
roles and verified workflow. A nonempty source folder is insufficient evidence.
